# Auction Draft Board

Open the app: https://thefiresays.github.io/draft-board/

To get an icon you can tap, open the link in Chrome, then choose **⋮ → Cast, save, and share → Install page as app**.

## How to use it

1. Type a few letters of a player's name.
2. Tap their name.
3. Type the price.
4. Tap **I won** or **Another team got them**.

Drafted players disappear from the list so no one is picked twice.

The green bar shows your money left, maximum next bid, and roster count. Your draft saves automatically on that device.

## If something goes wrong

- Wrong player or price? Tap **Undo**. You can tap it more than once.
- Missing player? Search for them, then use the add-player box that appears.
- Before draft day, go to **Settings → Save a backup file**. Restore it later from **Settings → Restore from a backup file**.

Settings also lets you change budget or roster size, turn off the falling footballs, and download results as a spreadsheet.
